# Week 20: `stack`、`queue`、`priority_queue` 与任务组织

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102B：标准库、并发与软件系统设计 |
| **关键词** | 栈、队列、优先队列、任务、事件 |
| **系统连接** | 不同顺序规则对应不同系统行为 |

## 学习目标

1. 使用 `std::stack` 表达后进先出
2. 使用 `std::queue` 表达先进先出
3. 使用 `std::priority_queue` 表达按优先级处理
4. 理解这些容器适配器在游戏和系统中的用途

## 核心概念

- 栈适合撤销、递归路径、状态回退
- 队列适合事件、任务、BFS
- 优先队列适合调度和 A* 开放集
- 容器适配器限制接口，换来更清楚的语义

## 课堂实践

- 用队列模拟游戏事件处理
- 用栈实现简单撤销
- 用优先队列处理“最紧急任务”

## 系统/设计连接

复杂软件中，任务不是总按写代码的顺序执行。队列和优先队列让系统可以按规则组织未来要发生的事情。
