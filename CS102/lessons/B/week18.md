# Week 18: 有序容器：`map`、`set` 和树结构直觉

| 项目 | 内容 |
|------|------|

| **系统连接** | 用有序结构维护可排序数据 |

## 学习目标

1. 使用 `std::map` 保存键值数据
2. 使用 `std::set` 保存唯一有序集合
3. 理解有序容器通常基于平衡树思想
4. 知道有序容器和哈希容器的取舍

## 核心概念

- `map` 保存 key -> value
- `set` 保存唯一 key
- 有序容器支持按顺序遍历
- 查找、插入、删除通常是对数复杂度

## 课堂实践

- 用 `map` 保存怪物图鉴
- 用 `set` 记录已解锁成就
- 输出按名称排序的资源列表

## 系统/设计连接

有序容器适合需要排序、范围查询或稳定遍历顺序的系统，例如编辑器面板、排行榜、调试输出。
