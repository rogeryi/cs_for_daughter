# Week 29: 期末项目：mini scene tree / 小型 2D 框架

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102B：标准库、并发与软件系统设计 |
| **关键词** | 期末项目、scene tree、update、event、resource |
| **系统连接** | 用小项目复现大型引擎的核心思想 |

## 学习目标

1. 设计一个简化版节点树
2. 实现 update 生命周期
3. 实现简单事件或 signal 机制
4. 管理资源表或任务队列

## 项目要求

项目建议包含：

- `Node` 基类
- 父子节点关系
- `update(double dt)` 生命周期
- 简单事件发送和接收
- 资源注册表
- 一个演示场景

## 可选扩展

- 简单任务队列
- 后台资源加载模拟
- JSON 或文本配置读取
- 简单碰撞或寻路演示

## 系统/设计连接

这个项目的价值不是做出完整引擎，而是让学生亲手体验“抽象、生命周期、事件、资源、模块”如何一起工作。

## 学习报告提示

- 你的 Node 树如何组织？
- update 调用顺序是什么？
- 哪个部分最像 Godot 的设计？
