# Week 25: `mutex`、`lock_guard`、`condition_variable`

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102B：标准库、并发与软件系统设计 |
| **关键词** | 互斥锁、RAII 锁、条件变量、等待通知 |
| **系统连接** | 多线程如何安全共享数据 |

## 学习目标

1. 理解共享数据需要同步
2. 使用 `std::mutex` 保护临界区
3. 使用 `std::lock_guard` 自动释放锁
4. 初步使用 `std::condition_variable` 等待事件
5. 在 Xcode 中观察线程等待、唤醒和共享数据变化

## 核心概念

- 临界区是访问共享状态的代码区域
- mutex 保证同一时间只有一个线程进入
- `lock_guard` 用 RAII 管理加锁和解锁
- condition variable 让线程等待条件发生

## 课堂实践

- 多线程累加计数器
- 观察没有锁时的错误结果
- 用条件变量实现生产者通知消费者

## Xcode 调试观察

- 在加锁前后设置断点
- 观察多个线程争用同一段临界区
- 在线程视图中观察等待通知的消费者线程
- 单步执行 `notify_one()` 后观察等待线程如何继续运行

## 系统/设计连接

线程同步不是为了“让代码看起来高级”，而是为了让共享状态保持一致。
