# Week 19: 无序容器：哈希表与资源查找

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102B：标准库、并发与软件系统设计 |
| **关键词** | `unordered_map`、`unordered_set`、哈希、资源表 |
| **系统连接** | 用 key 快速定位数据 |

## 学习目标

1. 使用 `std::unordered_map` 保存资源表
2. 理解哈希函数和桶的直觉
3. 知道哈希冲突存在但通常由容器处理
4. 比较 `map` 和 `unordered_map` 的使用场景

## 核心概念

- 哈希表通过 key 计算位置
- 无序容器不保证遍历顺序
- 平均查找效率高
- key 类型需要可哈希

## 课堂实践

- 实现一个素材路径到资源信息的查找表
- 查询贴图、音效、关卡配置
- 对比有序输出和无序输出

## 系统/设计连接

游戏引擎常用资源表把字符串路径或资源 ID 映射到实际资源。哈希表是理解资源管理器的重要数据结构。
