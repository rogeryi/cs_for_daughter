# Week 22: 文件系统与资源加载

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102B：标准库、并发与软件系统设计 |
| **关键词** | `std::filesystem`、路径、资源加载、序列化 |
| **系统连接** | 程序与磁盘文件交互 |

## 学习目标

1. 使用 `std::filesystem::path` 表达路径
2. 遍历目录和检查文件存在
3. 读取简单配置或资源清单
4. 理解资源加载器的基本职责

## 核心概念

- 路径不是普通字符串那么简单
- 相对路径依赖工作目录
- 资源加载器负责把磁盘数据转换成程序对象
- 序列化是对象和文件之间的转换

## 课堂实践

- 扫描 assets 目录
- 生成资源索引表
- 读取一个简单文本配置文件

## 系统/设计连接

游戏引擎中，资源系统是核心模块之一。贴图、声音、场景、脚本都需要从文件系统进入运行时对象。

- 相对路径为什么容易出问题？
- 资源加载器应该负责什么，不应该负责什么？
- 配置文件和程序对象之间如何转换？
