# Week 23: 时间、计时和游戏循环

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102B：标准库、并发与软件系统设计 |
| **关键词** | `std::chrono`、delta time、fixed update、游戏循环 |
| **系统连接** | 程序如何感知时间流逝 |

## 学习目标

1. 使用 `std::chrono` 测量时间
2. 理解 delta time 的意义
3. 理解游戏循环中的输入、更新、渲染阶段
4. 区分可变时间步和固定时间步的直觉

## 核心概念

- `steady_clock` 适合测量持续时间
- delta time 表示两帧之间经过的时间
- 游戏循环让程序持续响应世界变化
- 固定更新有助于稳定物理模拟

## 课堂实践

- 编写一个简化游戏循环
- 用 delta time 控制角色移动速度
- 打印每帧耗时和 FPS

## 系统/设计连接

游戏不是一次性计算，而是持续运行的交互系统。时间系统是动画、物理、输入反馈和性能分析的共同基础。
