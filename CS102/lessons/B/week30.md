# Week 30: 项目展示、源码分析报告和重构讨论

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102B：标准库、并发与软件系统设计 |
| **关键词** | 展示、源码分析、重构、复盘 |
| **系统连接** | 软件质量来自持续理解和改进 |

## 学习目标

1. 展示期末项目的功能和结构
2. 写出源码分析报告
3. 识别可以重构的模块
4. 总结一年 C/C++ 学习路线

## 展示内容

每个项目展示建议包括：

- 程序入口
- 核心类型
- 数据结构选择
- 生命周期设计
- 事件或任务流
- 最满意和最想改进的部分

## 源码分析报告

报告建议包含：

- 项目目录结构
- 核心模块职责
- 关键调用链
- 主要数据流
- 一个设计优点
- 一个重构建议

## 系统/设计连接

真正的软件能力不仅是写出代码，还包括解释代码、审查代码、修改代码和保留清晰结构。

## 学习报告提示

- 这一年最重要的 C++ 概念是什么？
- 你现在如何理解“复杂软件设计”？
- 如果继续学习图形学和游戏引擎，下一步最想深入什么？
