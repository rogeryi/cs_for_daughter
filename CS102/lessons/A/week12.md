# Week 12: 错误处理：`assert`、异常、`optional`、`expected`

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102A：现代 C++ 编程与内存模型 |
| **关键词** | 错误处理、断言、异常、`optional`、`expected` |
| **系统连接** | 程序如何表达失败 |

## 学习目标

1. 区分程序员错误和运行时失败
2. 使用 `assert` 检查不变量
3. 理解异常适合表达无法就地处理的失败
4. 使用 `std::optional` 和 `std::expected` 表达可能失败的结果

## 核心概念

- `assert` 用于发现“不应该发生”的情况
- 异常会改变正常控制流
- `optional<T>` 表达“可能没有值”
- `expected<T, E>` 表达“成功值或错误信息”

## 课堂实践

- 写一个资源查找函数，先返回 `optional`
- 写一个配置读取函数，返回 `expected`
- 讨论错误信息应该放在哪里

## 系统/设计连接

复杂软件不能假装错误不会发生。好的错误处理让失败可见、可定位、可恢复。
