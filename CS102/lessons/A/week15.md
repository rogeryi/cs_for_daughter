# Week 15: 上半学期项目：命令行小型系统

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102A：现代 C++ 编程与内存模型 |
| **关键词** | 多文件项目、标准库、RAII、错误处理、代码组织 |
| **系统连接** | 从语法学习走向小型软件系统 |

## 学习目标

1. 综合使用上半学期的 C++ 知识
2. 设计一个多文件命令行项目
3. 在项目中体现对象生命周期和资源管理
4. 写出第一份 C++ 项目设计说明

## 项目建议

可选方向：

- 命令行背包和资源管理器
- 简单 roguelike 房间探索
- 文本战斗模拟器
- 小型素材索引工具

## 必须使用

- `std::string`
- `std::vector`
- 至少一个自定义类
- 多文件结构
- 基础错误处理
- 一处体现 RAII 或智能指针思想的设计

## 系统/设计连接

项目重点不是功能越多越好，而是结构清楚。学生需要能解释每个文件负责什么，每个核心对象由谁拥有，失败时程序如何处理。

## 学习报告提示

- 项目中有哪些模块？
- 哪些地方使用了标准库容器？
- 项目里最重要的生命周期问题是什么？
