# Week 07: `std::string`、`std::string_view` 与 C 字符串

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102A：现代 C++ 编程与内存模型 |
| **关键词** | `std::string`、`std::string_view`、C 字符串、文本处理 |
| **系统连接** | 字符串是连续字符数据和长度信息的组合 |

## 学习目标

1. 熟练使用 `std::string`
2. 理解 C 字符串以 `'\0'` 结尾的传统表示
3. 初步理解 `std::string_view` 是非拥有视图
4. 避免不必要的字符串复制

## 核心概念

- `std::string` 拥有字符数据
- C 字符串依赖结束符判断长度
- `std::string_view` 观察字符串但不拥有数据
- 视图不能比被观察的数据活得更久

## 课堂实践

- 编写命令解析器：读取命令、拆分动词和参数
- 对比 `std::string` 拷贝和 `std::string_view` 观察
- 讨论悬空视图的风险

## 系统/设计连接

很多资源路径、配置文件、脚本命令本质上都是字符串。大型软件需要同时考虑易用性、性能和生命周期安全。
