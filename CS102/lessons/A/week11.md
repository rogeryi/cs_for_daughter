# Week 11: 头文件、源文件、命名空间、编译与链接

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102A：现代 C++ 编程与内存模型 |
| **关键词** | `.h`、`.cpp`、命名空间、翻译单元、链接 |
| **系统连接** | 多文件项目如何变成一个程序 |

## 学习目标

1. 把程序拆分成头文件和源文件
2. 理解声明和定义的区别
3. 使用命名空间组织代码
4. 理解编译和链接的基本错误类型

## 核心概念

- 头文件通常放声明
- 源文件通常放实现
- 每个 `.cpp` 会成为一个翻译单元
- 链接器负责把多个目标文件连接成程序

## 课堂实践

- 把 `Character` 拆成 `character.h` 和 `character.cpp`
- 故意制造一次重复定义错误
- 使用 CMake 构建多文件项目

## 系统/设计连接

源码分析首先要知道文件之间如何连接。头文件像模块的公开接口，源文件像实现细节。

## 学习报告提示

- 声明和定义有什么区别？
- 为什么多文件项目需要链接？
- 头文件为什么不能随便放全局变量定义？
