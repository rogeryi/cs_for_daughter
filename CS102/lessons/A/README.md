# CS102A: 现代 C++ 编程与内存模型

CS102A 是 CS102 的上半部分，共 15 节课。目标是让学生从 Python 平稳过渡到现代 C++，并在写程序的过程中理解类型、内存、地址、生命周期、对象和资源管理。

本部分以 Xcode IDE 为主教学环境。每节课都尽量安排一次调试器观察：断点、单步执行、变量面板、调用栈、地址输出、Memory Graph 或对象生命周期观察。

---

## 课程主线

```
C++ 开发环境
  -> 类型、函数、引用
  -> 地址、指针、数组
  -> 栈、堆、生命周期
  -> string/vector/class
  -> RAII 与智能指针
  -> 编译链接与错误处理
  -> 标准算法与 ranges
  -> 上半学期项目
```
