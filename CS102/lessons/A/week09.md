# Week 09: `struct`、`class`、构造函数和封装

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102A：现代 C++ 编程与内存模型 |
| **关键词** | `struct`、`class`、构造函数、析构函数、封装 |
| **系统连接** | 对象把数据和生命周期组织在一起 |

## 学习目标

1. 定义简单的 `struct` 和 `class`
2. 使用构造函数建立有效对象
3. 使用析构函数观察对象销毁
4. 理解封装不是“隐藏”，而是保护不变量

## 核心概念

- `struct` 默认 public，`class` 默认 private
- 构造函数负责创建有效初始状态
- 析构函数负责对象结束时的清理
- 封装让对象维护自己的规则

## 课堂实践

- 实现 `Character` 类
- 保证生命值不会小于 0 或超过最大值
- 添加 `take_damage`、`heal`、`is_alive`

## 系统/设计连接

复杂软件中的类型不只是数据容器，而是规则的边界。好的类让错误状态更难出现，让源码阅读者更容易理解系统。
