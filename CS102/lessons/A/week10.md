# Week 10: 所有权与智能指针

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102A：现代 C++ 编程与内存模型 |
| **关键词** | 所有权、`unique_ptr`、`shared_ptr`、`weak_ptr` |
| **系统连接** | 谁负责销毁对象 |

## 学习目标

1. 理解所有权是生命周期管理问题
2. 使用 `std::unique_ptr` 表达唯一拥有
3. 理解 `std::shared_ptr` 的共享拥有语义
4. 知道 `std::weak_ptr` 可打破循环引用

## 核心概念

- 裸指针不表达所有权
- `unique_ptr` 不能复制，只能移动
- `shared_ptr` 通过引用计数共享对象
- 共享所有权会增加设计复杂度

## 课堂实践

- 用 `unique_ptr` 管理不同类型的游戏对象
- 建立一个资源缓存示例，讨论何时共享
- 画出对象所有权图

## 系统/设计连接

大型软件最难的 bug 很多来自“对象到底该由谁销毁”。智能指针是现代 C++ 管理生命周期的重要工具，但设计上仍要尽量保持所有权清晰。
