# Week 13: 标准算法与 lambda

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102A：现代 C++ 编程与内存模型 |
| **关键词** | 标准算法、迭代器、lambda、谓词 |
| **系统连接** | 把“怎么循环”交给标准库 |

## 学习目标

1. 使用 `std::sort`、`std::find_if`、`std::count_if`
2. 理解迭代器是容器和算法之间的桥梁
3. 编写简单 lambda 表达式
4. 用算法替代重复的手写循环
5. 在 Xcode 中观察 lambda 捕获变量后的闭包状态

## 核心概念

- 标准算法表达常见数据操作
- lambda 可以在使用处定义小函数
- 谓词是返回 bool 的判断逻辑
- 算法让代码更接近“意图”

## 课堂实践

- 对角色列表按生命值排序
- 查找第一个可购买道具
- 统计背包中稀有物品数量

## Xcode 调试观察

- 在 lambda 内部设置断点
- 观察调用栈中标准算法调用 lambda 的位置
- 对比按值捕获 `[limit]` 和按引用捕获 `[&limit]`
- 在变量面板中查看捕获变量如何成为闭包对象的状态
- 讨论 lambda 不是魔法，而是“带有状态的匿名函数对象”

## 系统/设计连接

读源码时，算法调用通常比手写循环更容易理解意图。现代 C++ 倾向把常见遍历模式交给标准库。

- 为什么标准算法能提高可读性？
- 调试器中看到的捕获变量如何帮助你理解闭包？
