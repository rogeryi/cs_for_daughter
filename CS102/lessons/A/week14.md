# Week 14: ranges 与数据处理管线

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102A：现代 C++ 编程与内存模型 |
| **关键词** | ranges、views、filter、transform、管线 |
| **系统连接** | 延迟处理和数据流表达 |

## 学习目标

1. 初步使用 C++ ranges
2. 理解 view 通常不拥有数据
3. 使用 filter 和 transform 组织数据处理
4. 知道 ranges 是现代 C++ 的重要方向，但不深挖复杂模板机制

## 核心概念

- range 是可遍历的数据范围
- view 是轻量的观察和转换工具
- 管线表达“先过滤，再转换，再使用”
- view 的生命周期要依赖原始数据

## 课堂实践

- 从物品列表中过滤可装备物品
- 把角色列表转换成名字列表
- 对比 ranges 写法和传统循环写法

## 系统/设计连接

大型软件经常需要从一批数据中筛选、转换和展示。ranges 让数据处理流程更接近人类描述。
