# Week 08: `std::vector`、`std::array`、`std::span` 与连续内存

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102A：现代 C++ 编程与内存模型 |
| **关键词** | `vector`、`array`、`span`、连续内存、容量 |
| **系统连接** | 数据布局影响性能和指针有效性 |

## 学习目标

1. 使用 `std::vector` 管理动态数量的数据
2. 使用 `std::array` 表达固定大小数组
3. 理解 `std::span` 是连续数据视图
4. 理解 vector 扩容可能导致地址变化
5. 使用 Xcode 观察 vector 数据区地址和扩容后的变化

## 核心概念

- `std::vector` 是最常用的连续动态数组
- `size()` 是已有元素数量，`capacity()` 是当前容量
- 扩容可能搬家，旧指针和引用可能失效
- `std::span` 适合“借用一段连续数据”

## 课堂实践

- 用 `std::vector` 保存敌人列表
- 打印扩容前后的元素地址
- 用 `std::span` 编写只处理数组片段的函数

## Xcode 调试观察

- 在 `push_back` 前后设置断点
- 观察 `size()` 和 `capacity()` 的变化
- 保存第一个元素地址，再继续添加元素
- 当 vector 扩容后，对比旧地址和新地址
- 讨论为什么保存 vector 元素指针是一件需要谨慎的事

## 系统/设计连接

游戏开发常偏好连续内存，因为遍历大量对象时缓存友好。理解 vector 是以后学习 ECS、渲染缓冲区和资源表的基础。
