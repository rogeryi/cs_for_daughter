# Week 06: 栈、堆、生命周期和 RAII 初识

## 课程信息

| 项目 | 内容 |
|------|------|
| **所属部分** | CS102A：现代 C++ 编程与内存模型 |
| **关键词** | 栈、堆、作用域、生命周期、RAII |
| **系统连接** | 对象何时创建，何时销毁 |

## 学习目标

1. 理解局部对象的生命周期
2. 区分栈上对象和动态分配对象
3. 理解资源泄漏的基本原因
4. 初识 RAII：对象负责资源释放
5. 使用 Xcode 观察对象创建、销毁和简单对象关系

## 核心概念

- 作用域结束时局部对象会销毁
- 堆对象需要明确的所有权管理
- RAII 把资源生命周期绑定到对象生命周期
- 现代 C++ 尽量避免手动 `new/delete`

## 课堂实践

- 写一个作用域实验，观察构造和析构顺序
- 打开文件并通过对象自动关闭
- 讨论如果忘记释放资源会怎样

## Xcode 调试观察

- 在构造函数和析构函数中设置断点
- 观察调用栈如何从 `main()` 进入对象构造和析构
- 在变量面板中比较局部对象和智能指针管理的对象
- 使用 Memory Graph 观察简单对象之间的指针关系

## 系统/设计连接

生命周期是 C++ 软件稳定性的核心。游戏引擎中的纹理、声音、场景节点、文件句柄都需要清楚的生命周期管理。

## 学习报告提示

- 什么是对象生命周期？
- RAII 为什么能减少资源泄漏？
- 栈和堆的区别不应该只理解成“快慢”，还应该理解成什么？
- Xcode 如何帮助你看到对象生命周期？
