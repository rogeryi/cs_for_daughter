# Verity 养成游戏设计

## 1. 项目目标

在 `CS101/week11` 中制作一个使用 Pygame Zero 运行的小型养成游戏。

项目服务于 CS101 第 11 课“类与对象初识”，让学生通过一个可互动角色理解：

- 类是对象的模板
- 对象用属性保存状态
- 方法表示对象可以执行的行为
- `__init__` 负责初始化对象
- `self` 表示当前对象
- 状态机可以控制对象在不同状态下的行为

游戏角色名为 Verity，默认外观是一个黄色、Emoji 风格的小球。

## 2. 功能范围

游戏包含以下日常互动：

- 喂食
- 玩耍
- 洗澡
- 聊天
- 装扮
- 暂时离开

Verity 具有五项状态：

- 心情值 `mood`
- 饱食度 `fullness`
- 清洁度 `cleanliness`
- 体力 `energy`
- 亲密度 `bond`

所有互动都会改变心情值。游戏采用轻松模式，状态不会随时间自动下降，只在玩家执行互动时变化。

## 3. 初始状态

Verity 创建时使用以下初始值：

| 属性 | 初始值 |
|---|---:|
| 心情值 | 70 |
| 饱食度 | 60 |
| 清洁度 | 70 |
| 体力 | 70 |
| 亲密度 | 20 |
| 当前装扮 | 无 |
| 当前状态 | `normal` |

所有数值都限制在 `0` 到 `100` 之间。

## 4. 互动规则

| 行为 | 心情变化 | 其他变化 |
|---|---:|---|
| 喂食 | `+8` | 饱食 `+25`、清洁 `-2`、体力 `+2`、亲密 `+3` |
| 玩耍 | `+15` | 饱食 `-8`、清洁 `-5`、体力 `-15`、亲密 `+10` |
| 洗澡 | `+5` | 清洁 `+30`、体力 `-3`、亲密 `+6` |
| 聊天 | `+10` | 体力 `-1`、亲密 `+12` |
| 装扮 | `+12` | 体力 `-4`、亲密 `+8`，切换到下一件装扮 |
| 暂时离开 | `-25` | 亲密 `-10` |

装扮按以下顺序循环：

```text
无 -> 蝴蝶结 -> 帽子 -> 眼镜 -> 无
```

每次行为执行后，程序都要：

1. 修改对应属性
2. 把所有属性限制到 `0` 到 `100`
3. 生成一句 Verity 的反馈对白
4. 检查是否需要切换状态

## 5. 状态机

状态使用简单字符串常量表示：

```python
STATE_NORMAL = "normal"
STATE_MONSTER = "monster"
STATE_RECOVERING = "recovering"
```

### 5.1 正常状态

在 `normal` 状态：

- Verity 显示为黄色小球
- 显示五项状态条
- 显示六个日常互动按钮
- 每次互动调用 Verity 对象的对应方法

当心情值下降到 `0` 时，立即进入 `monster` 状态。

### 5.2 怪物状态

在 `monster` 状态：

- Verity 变成紫色、不规则形状的怪物
- 使用愤怒或受伤的表情
- 隐藏六个日常互动按钮
- 只显示“道歉”和“示弱”两个按钮
- 日常互动方法不再生效

点击“道歉”或“示弱”后进入 `recovering` 状态。

### 5.3 恢复状态

在 `recovering` 状态：

- 播放约 1 秒的颜色与表情恢复效果
- 暂停所有按钮交互
- 恢复完成后把心情值设为 `30`
- 重新进入 `normal` 状态

道歉和示弱采用相同的状态转换，但显示不同对白。

状态转换流程：

```text
normal
  -> mood == 0
monster
  -> apologize() 或 show_weakness()
recovering
  -> 1 秒计时结束
normal，mood = 30
```

## 6. 界面设计

视觉方向采用“温馨小屋”：

- 明亮的蓝绿色墙面
- 木质地板
- 简单窗户和盆栽装饰
- 中央显示 Verity
- 顶部显示角色名和五项状态条
- Verity 上方显示对白气泡
- 底部显示互动按钮

正常状态底部按钮：

```text
喂食 | 玩耍 | 洗澡 | 聊天 | 装扮 | 暂时离开
```

怪物状态底部按钮：

```text
道歉 | 示弱
```

Verity 的主体使用 Pygame 绘图函数绘制圆形、眼睛和嘴巴，不依赖系统彩色 Emoji 字体。按钮可以显示中文文字和简单符号，保证字体不支持 Emoji 时仍能使用。

## 7. 代码结构

```text
CS101/week11/
├── verity.py
├── verity_game.py
└── test_verity.py
```

### 7.1 `verity.py`

负责纯游戏逻辑：

- 定义 `Verity` 类
- 初始化五项属性
- 实现六个日常互动方法
- 实现 `apologize()` 和 `show_weakness()`
- 限制属性范围
- 检查和切换状态
- 通过 `update_recovery(dt)` 管理恢复计时
- 管理装扮循环
- 保存当前反馈对白

该文件不依赖 Pygame Zero，便于独立测试。

互动方法返回布尔值：行为成功执行时返回 `True`，因当前状态不允许而被忽略时返回 `False`。无效行为不得修改任何属性。

### 7.2 `verity_game.py`

负责图形界面：

- 创建唯一对象 `verity = Verity("Verity")`
- 定义 Pygame Zero 窗口尺寸
- 在 `draw()` 中绘制房间、状态条、Verity、对白和按钮
- 在 `on_mouse_down()` 中判断点击了哪个按钮
- 根据当前状态调用 Verity 的方法
- 在 Pygame Zero 的 `update(dt)` 中调用 `verity.update_recovery(dt)`

### 7.3 `test_verity.py`

负责验证纯逻辑，不打开图形窗口。

## 8. 输入与数据流

一次普通互动的数据流：

```text
鼠标点击按钮
  -> on_mouse_down()
  -> 调用 verity.feed() 等方法
  -> 更新对象属性与对白
  -> check_state()
  -> draw() 按新数据重绘界面
```

怪物恢复的数据流：

```text
心情归零
  -> 状态变为 monster
  -> 玩家点击道歉或示弱
  -> 状态变为 recovering
  -> update(dt) 累加时间
  -> 1 秒后 mood = 30，状态变为 normal
```

## 9. 边界与保护规则

- 所有数值变化后都要限制在 `0` 到 `100`
- 当前处于正常状态且心情值达到 `0` 时，执行一次到怪物状态的转换；恢复正常后再次归零仍可再次变成怪物
- 怪物状态忽略日常互动
- 正常状态忽略道歉和示弱
- 恢复状态忽略全部点击
- 被忽略的互动返回 `False`，且不修改属性、装扮或恢复计时
- 恢复计时达到 1 秒后只执行一次状态转换
- 按钮点击只在按钮矩形范围内生效
- 窗口关闭由 Pygame Zero 自身处理

## 10. 测试设计

逻辑测试至少覆盖：

1. 创建 Verity 后五项属性和状态正确
2. 喂食正确修改各项属性
3. 玩耍正确修改各项属性
4. 洗澡正确修改各项属性
5. 聊天正确修改各项属性
6. 装扮正确修改属性并循环切换装扮
7. 暂时离开正确降低心情和亲密度
8. 所有属性保持在 `0` 到 `100`
9. 心情降到 `0` 后进入怪物状态
10. 怪物状态不能执行日常互动
11. 道歉进入恢复状态
12. 示弱进入恢复状态
13. 恢复不足 1 秒时保持恢复状态
14. 恢复满 1 秒后回到正常状态并将心情设为 `30`

图形界面进行人工检查：

- 正常状态的五项状态条与数值一致
- 六个按钮均能触发正确方法
- 装扮能正确切换
- 心情归零后外观和按钮发生变化
- 恢复过程中按钮不可用
- 1 秒后恢复黄色小球外观

## 11. 运行方式

安装 Pygame Zero 后，在 `CS101/week11` 目录执行：

```powershell
python -X utf8 -m pgzero verity_game.py
```

逻辑测试使用 Python 直接执行：

```powershell
python test_verity.py
```

## 12. 验收标准

项目完成需满足：

- 能以 Pygame Zero 窗口启动
- Verity 默认显示为黄色 Emoji 风格小球
- 五项状态可见且只因互动而变化
- 六种日常互动均可点击
- 所有互动都会影响心情值
- 心情归零后进入怪物状态
- 怪物状态只能选择道歉或示弱
- 任一恢复行为都能在约 1 秒后恢复正常
- 恢复后心情值为 `30`
- 逻辑测试全部通过
- 代码能够清楚展示类、对象、属性、方法、`__init__` 和 `self`
