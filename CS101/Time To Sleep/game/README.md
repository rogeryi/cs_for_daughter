## 🎮 操作说明

| 操作 | 按键 | 功能 |
|------|------|------|
| **移动** | A/D 或 ←/→ | 左右移动 |
| **跳跃** | Space | 跳跃（可变高度） |
| **攻击** | J 或 Z | 近战攻击（支持3段连击） |
| **冲刺** | K 或 X | 短距离冲刺（有无敌帧） |
| **治疗** | E | 恢复生命值（需要站立不动） |
| **重新开始** | R | 游戏结束后重新开始 |

## 📊 技术规格

### 游戏配置

- **窗口大小：** 960 × 540
- **帧率：** 60 FPS
- **玩家速度：** 4 像素/帧
- **跳跃力度：** -12
- **重力：** 0.6 像素/帧²

### 数值平衡

| 属性 | 初始值 | 最大值 |
|------|-------|-------|
| 生命值（HP） | 50 | 90 |
| 攻击力（ATK） | 5 | 12 |
| 治疗次数 | 2 | 4 |
| 配件槽位 | 3 | 5 |
| 装备点数 | 9 | 15 |

## 🎓 学习要点

通过开发这个游戏，你将学习：

1. **游戏循环：** update() 和 draw() 的工作原理
2. **碰撞检测：** Rect.colliderect() 的使用
3. **状态机：** 玩家/敌人状态管理
4. **粒子系统：** 视觉效果实现
5. **摄像机系统：** 跟随玩家的镜头
6. **UI 设计：** 血条、文字渲染
7. **游戏平衡：** 数值调整技巧
