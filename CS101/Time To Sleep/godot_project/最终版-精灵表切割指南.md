## 🎮 完整操作步骤

### 步骤 1️⃣：配置精灵导入选项

**在 Godot FileSystem 面板中：**

依次对 3 个文件执行以下操作：

1. **点击文件**（`demo待机.png`）
2. **查看 Import 面板**（左下角）
3. **设置参数：**
   ```
   ✅ Preset: 2D Pixel
   ✅ Filter: Nearest
   ❌ Mipmaps: 取消勾选
   ✅ Repeat: Disabled
   ```
4. **点击 Reimport 按钮**

5. **重复以上步骤**处理：
   - `demo移动.png`
   - `demo跳跃.png`

---

### 步骤 2️⃣：打开玩家场景

**在 FileSystem 中：**
```
双击: scenes/player.tscn
```

场景会在编辑器中打开。

---

### 步骤 3️⃣：选择 AnimatedSprite2D 节点

**在场景树面板（左上角）中：**
```
Player (CharacterBody2D)
└── AnimatedSprite2D  ← 点击这个
```

---

### 步骤 4️⃣：创建 SpriteFrames 资源

**在 Inspector 面板（右上角）中：**

1. 找到 **Sprite Frames** 属性
2. 点击下拉菜单 → 选择 **New SpriteFrames**
3. 点击 **Sprite Frames** 旁边出现的 **[点击打开]** 图标

这会打开 **SpriteFrames 编辑器**（在底部面板）。

---

### 步骤 5️⃣：切割待机动画（Idle）

#### 5.1 重命名动画
1. 在编辑器**左侧动画列表**中
2. **双击** `default`
3. **输入：** `idle`
4. **按 Enter** 确认

#### 5.2 添加精灵表帧
1. 点击编辑器**底部**的 **📁 从精灵表添加帧** 按钮
2. 在弹出的文件选择器中：
   - 导航到：`assets/sprites/`
   - 选择：`demo待机.png`
   - 点击 **打开**

#### 5.3 配置切割参数
在弹出的对话框中：
```
Horizontal: 2
Vertical: 2
```
点击 **OK**

#### 5.4 设置动画参数
在编辑器左侧，确保 `idle` 被选中，然后设置：
```
Speed (FPS): 8
✅ Loop: 勾选
```

**✅ 待机动画完成！应该看到 4 帧。**

---

### 步骤 6️⃣：切割移动动画（Run）

#### 6.1 创建新动画
1. 点击左侧动画列表上方的 **+** 按钮
2. **输入：** `run`
3. **按 Enter** 确认

#### 6.2 添加精灵表帧
1. 点击 **📁 从精灵表添加帧**
2. 选择：`demo移动.png`
3. 点击 **打开**

#### 6.3 配置切割参数
```
Horizontal: 2
Vertical: 2
```
点击 **OK**

#### 6.4 设置动画参数
```
Speed (FPS): 10
✅ Loop: 勾选
```

**✅ 移动动画完成！应该看到 4 帧。**

---

### 步骤 7️⃣：切割跳跃动画（Jump）⚠️

#### 7.1 创建新动画
1. 点击 **+** 按钮
2. **输入：** `jump`
3. **按 Enter** 确认

#### 7.2 添加精灵表帧
1. 点击 **📁 从精灵表添加帧**
2. 选择：`demo跳跃.png`
3. 点击 **打开**

#### 7.3 配置切割参数
```
Horizontal: 3
Vertical: 3
```
点击 **OK**

#### 7.4 删除空白帧 ⚠️ 重要！

**此时会生成 9 帧，但只需要 7 帧！**

1. 在**底部帧列表**中，您会看到 9 个帧
2. **选中最后 2 帧**（帧7和帧8，它们是空白的）
   - 点击帧7选中
   - 按住 Shift 点击帧8（同时选中帧7和帧8）
3. 点击帧列表上方的 **🗑️ 删除帧** 按钮
4. **确认：** 现在应该只剩 7 帧（帧0-帧6）

#### 7.5 设置动画参数
```
Speed (FPS): 15
❌ Loop: 取消勾选
```

**✅ 跳跃动画完成！应该看到 7 帧。**

---

### 步骤 8️⃣：设置默认动画

1. **关闭 SpriteFrames 编辑器**（点击右上角的 X）

2. 确保 **AnimatedSprite2D** 节点仍被选中

3. 在 **Inspector** 中找到：
   ```
   Animation: [下拉菜单]
   ```

4. **选择：** `idle`

5. **勾选** 下方的 **Autoplay**

---

### 步骤 9️⃣：保存场景

**按快捷键：**
```
Mac: Cmd + S
```

或点击菜单：
```
Scene → Save Scene
```

---

### 步骤 🔟：运行测试

1. **按 F5** 或点击右上角的 **▶️ 播放** 按钮

2. Godot 会提示选择主场景：
   - 选择：`res://scenes/test_level.tscn`
   - 点击 **Select**

3. **游戏窗口打开！** 🎉

## 🎯 测试动画

### 在游戏窗口中：

| 操作 | 按键 | 预期效果 |
|------|------|---------|
| 向左移动 | **A** 或 **←** | 播放 run 动画，角色翻转朝左 |
| 向右移动 | **D** 或 **→** | 播放 run 动画，角色朝右 |
| 跳跃 | **Space** | 播放 jump 动画（7帧，不循环） |
| 静止不动 | 无 | 播放 idle 动画（4帧循环） |

### 动画切换逻辑：
```
静止 → idle 动画（循环）
  ↓ 按 A/D
移动 → run 动画（循环）
  ↓ 按 Space
跳跃 → jump 动画（播放一次）
  ↓ 落地后
回到 → idle 或 run 动画
```

## 🔧 常见问题

### ❌ 问题 1：动画不显示

**解决方案：**
1. 检查精灵表是否正确导入（有缩略图）
2. 确认 Filter 设置为 **Nearest**
3. 重新导入（选择文件 → Reimport）

### ❌ 问题 2：看到空白帧

**解决方案：**
1. 打开 SpriteFrames 编辑器
2. 选中空白帧
3. 点击 **🗑️ 删除帧**

### ❌ 问题 3：动画播放太快/太慢

**解决方案：**
1. 打开 SpriteFrames 编辑器
2. 选中对应动画
3. 调整 **Speed (FPS)** 值

### ❌ 问题 4：角色方向错误

**解决方案：**
代码已自动处理翻转，检查 `player.gd`：
```gdscript
animated_sprite.flip_h = not facing_right
```
