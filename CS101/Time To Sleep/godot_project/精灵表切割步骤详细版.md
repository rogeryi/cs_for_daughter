## ✂️ 第四步：切割精灵表

### 4.1 打开玩家场景

1. 在 **FileSystem** 中双击：`scenes/player.tscn`
2. 场景会在编辑器中打开

### 4.2 选择 AnimatedSprite2D 节点

在 **场景树**（左上角）中点击：
```
Player (CharacterBody2D)
└── AnimatedSprite2D  ← 点击这个
```

### 4.3 创建 SpriteFrames 资源

1. 在 **Inspector** 面板（右上角）中找到：
   ```
   Sprite Frames: [空]
   ```

2. 点击下拉菜单 → 选择 **New SpriteFrames**

3. 点击 **Sprite Frames** 旁边出现的 **[点击打开]** 图标
   - 这会打开 **SpriteFrames 编辑器**（在底部面板）

### 4.4 切割待机动画（Idle）

#### 步骤：
1. **重命名默认动画：**
   - 在 SpriteFrames 编辑器左侧的动画列表中
   - 双击 `default`
   - 重命名为 `idle`
   - 按 Enter 确认

2. **添加精灵表帧：**
   - 点击编辑器底部的 **📁 从精灵表添加帧** 按钮
   - 在弹出的文件选择器中：
     - 导航到：`assets/sprites/`
     - 选择：`demo待机.png`
     - 点击 **打开**

3. **配置切割参数：**
   
   **如果精灵表是水平排列（一行多列）：**
   ```
   Horizontal: [输入帧数，例如 3 或 4]
   Vertical: 1
   ```
   
   **如果精灵表是网格排列（多行多列）：**
   ```
   Horizontal: [每行的帧数，例如 2]
   Vertical: [行数，例如 2]
   ```

4. **确认切割：**
   - 点击 **OK**
   - 您应该在下方的帧列表中看到所有帧

5. **设置动画参数：**
   ```
   Speed (FPS): 8
   ✅ Loop: 勾选
   ```

### 4.5 切割移动动画（Run）

#### 步骤：
1. **创建新动画：**
   - 点击左侧动画列表上方的 **+** 按钮
   - 输入：`run`
   - 按 Enter 确认

2. **添加精灵表帧：**
   - 点击 **📁 从精灵表添加帧**
   - 选择：`demo移动.png`
   - 点击 **打开**

3. **配置切割参数：**
   ```
   Horizontal: [与待机相同的帧数]
   Vertical: 1（或网格行数）
   ```

4. **设置动画参数：**
   ```
   Speed (FPS): 10
   ✅ Loop: 勾选
   ```

### 4.6 切割跳跃动画（Jump）

#### 步骤：
1. **创建新动画：**
   - 点击 **+** 按钮
   - 输入：`jump`
   - 按 Enter 确认

2. **添加精灵表帧：**
   - 点击 **📁 从精灵表添加帧**
   - 选择：`demo跳跃.png`
   - 点击 **打开**

3. **配置切割参数：**
   ```
   Horizontal: [帧数]
   Vertical: [行数]
   ```

4. **设置动画参数：**
   ```
   Speed (FPS): 15
   ❌ Loop: 取消勾选（跳跃只播放一次）
   ```

## ▶️ 第五步：设置和测试

### 5.1 设置默认动画

1. 关闭 SpriteFrames 编辑器（点击编辑器右上角的 X）

   - 点击 **Select**

3. 游戏窗口会打开！

### 5.4 测试动画

在游戏窗口中：
```
按 A 或 ← : 向左移动（应该播放 run 动画，角色翻转）

不动      : 待机（应该播放 idle 动画）
```

## 🔧 常见问题和解决方案

### ❌ 问题 1：动画不显示

**可能原因：** 精灵表没有正确导入

**解决方案：**
1. 检查 FileSystem 中精灵表文件是否有缩略图
2. 重新导入（选择文件 → Import 面板 → Reimport）
3. 确保 Filter 设置为 **Nearest**

### ❌ 问题 2：动画帧切割错误

**症状：** 看到部分帧或空白

**解决方案：**
1. 打开 SpriteFrames 编辑器
2. 选中错误的动画
3. 点击 **🗑️ 删除所有帧**（垃圾桶图标）
4. 重新添加精灵表，调整 Horizontal/Vertical 参数

### ❌ 问题 3：动画播放太快/太慢

**解决方案：**
1. 打开 SpriteFrames 编辑器
2. 选中对应动画
3. 调整 **Speed (FPS)** 值：
   - idle: 6-8
   - run: 10-12
   - jump: 15-20

### ❌ 问题 4：角色翻转后方向错误

**解决方案：**
代码已自动处理，如果仍有问题，检查 `player.gd` 中：
```gdscript
animated_sprite.flip_h = not facing_right
```
