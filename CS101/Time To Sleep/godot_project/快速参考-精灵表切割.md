## 🎮 操作步骤（简化版）

### 1️⃣ 导入设置（3个文件都做）
```
选择文件 → Import 面板 → 
✅ Filter: Nearest
❌ Mipmaps: 关闭
→ 点击 Reimport
```

### 2️⃣ 打开场景
```
双击: scenes/player.tscn
```

### 3️⃣ 创建 SpriteFrames
```
场景树 → 选择 AnimatedSprite2D
Inspector → Sprite Frames → New SpriteFrames
→ 点击 [点击打开]
```

### 4️⃣ 切割动画

#### 待机（idle）
```
1. 重命名 default → idle
2. 📁 从精灵表添加帧 → demo待机.png
3. Horizontal: 2, Vertical: 2
4. Speed: 8 FPS, ✅ Loop
```

#### 移动（run）
```
1. + 新建动画 → run
2. 📁 从精灵表添加帧 → demo移动.png
3. Horizontal: 2, Vertical: 2
4. Speed: 10 FPS, ✅ Loop
```

#### 跳跃（jump）
```
1. + 新建动画 → jump
2. 📁 从精灵表添加帧 → demo跳跃.png
3. Horizontal: 3, Vertical: 3
4. Speed: 15 FPS, ❌ Loop
5. 删除最后 2 个空白帧（帧7和帧8）
```

### 5️⃣ 完成设置
```
1. 关闭 SpriteFrames 编辑器
2. Animation: 选择 idle
3. ✅ 勾选 Autoplay
4. Ctrl+S 保存
5. F5 运行测试
```

## 🎯 测试操作

```
A / ←  : 向左移动
D / →  : 向右移动
Space  : 跳跃
不动   : 待机动画
```
