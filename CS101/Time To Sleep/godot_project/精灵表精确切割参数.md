## 🎮 Godot 切割参数

### ✅ 待机动画（Idle）

**在 SpriteFrames 编辑器中：**

1. **选择动画：** `idle`
2. **点击：** 📁 从精灵表添加帧
3. **选择文件：** `demo待机.png`
4. **设置参数：**
   ```
   Horizontal: 2
   Vertical: 2
   ```
5. **点击：** OK
6. **设置速度：**
   ```
   Speed (FPS): 8
   ✅ Loop: 勾选
   ```

---

## 📝 完整操作步骤（待确认后执行）

### 步骤 1：配置精灵导入

在 Godot FileSystem 中，对 3 个文件依次执行：

1. 点击文件
2. Import 面板设置：
   ```
   ✅ Preset: 2D Pixel
   ✅ Filter: Nearest
   ❌ Mipmaps: 取消勾选
   ```
3. 点击 **Reimport**

### 步骤 2：打开场景

双击：`scenes/player.tscn`

### 步骤 3：选择节点

场景树中点击：`Player → AnimatedSprite2D`

### 步骤 4：创建 SpriteFrames

1. Inspector → **Sprite Frames** → **New SpriteFrames**
2. 点击 **[点击打开]** 图标

### 步骤 5：切割待机动画

1. 双击左侧 `default` → 重命名为 `idle`
2. 点击 **📁 从精灵表添加帧**
3. 选择 `demo待机.png`
4. 设置：
   ```
   Horizontal: 2
   Vertical: 2
   ```
5. 点击 OK
6. 设置：
   ```
   Speed (FPS): 8
   ✅ Loop: 勾选
   ```

### 步骤 6：切割移动动画

1. 点击左侧 **+** → 输入 `run`
2. 点击 **📁 从精灵表添加帧**
3. 选择 `demo移动.png`
4. 设置：
   ```
   Horizontal: 2
   Vertical: 2
   ```
5. 点击 OK
6. 设置：
   ```
   Speed (FPS): 10
   ✅ Loop: 勾选
   ```

### 步骤 7：切割跳跃动画

1. 点击左侧 **+** → 输入 `jump`
2. 点击 **📁 从精灵表添加帧**
3. 选择 `demo跳跃.png`
4. 设置：
   ```
   Horizontal: 3
   Vertical: 3
   ```
5. 点击 OK
6. **删除空白帧：**
   - 在帧列表中会看到 9 帧
   - 选中最后 2 帧（空白帧）
   - 点击 **🗑️ 删除帧** 按钮
   - 确保只剩 7 个有效帧（帧0-帧6）
7. 设置：
   ```
   Speed (FPS): 15
   ❌ Loop: 取消勾选
   ```

### 步骤 8：设置默认动画

1. 关闭 SpriteFrames 编辑器
2. Inspector → **Animation** → 选择 `idle`
3. ✅ 勾选 **Autoplay**

### 步骤 9：保存并测试

1. **Ctrl + S** 保存场景
2. 按 **F5** 运行
3. 测试动画播放

## 💡 提示

### 如何查看精灵表布局？

在 macOS 的"预览"中：
1. 打开图片
2. 查看 → 显示检查器（Cmd + I）
3. 可以看到图片尺寸

或者直接用眼睛数：
- 有几行？
- 每行有几帧？
- 最后一行是否完整？

### 如果切割后帧顺序不对？

在 SpriteFrames 编辑器中：
1. 选中帧
2. 拖拽调整顺序
3. 或者删除后重新添加
