# 🎨 Pixel Studio 精灵表导入 Godot 完整指南

## 📋 准备工作

### 1. 从 Pixel Studio 导出精灵表

#### 导出设置：
1. 打开 Pixel Studio 项目
2. 点击 **File → Export → Sprite Sheet**
3. 设置参数：
   - **Format:** PNG
   - **Frame Width:** 32 或 64（根据您的角色尺寸）
   - **Frame Height:** 32 或 64
   - **Columns:** 自动或手动设置
   - **Rows:** 自动或手动设置
   - **Background:** Transparent（透明背景）

#### 需要导出的动画：
- ✅ **idle.png** - 待机动画（建议 4-8 帧）
- ✅ **run.png** - 移动动画（建议 8-12 帧）
- ✅ **jump.png** - 跳跃动画（建议 4-8 帧）

## 🎮 Godot 导入步骤

### 方法一：使用 Godot 编辑器（推荐）

#### 步骤 1：打开项目
```bash
cd "/Users/roger/cs/CS101/Time To Sleep/godot_project"
godot
```

#### 步骤 2：导入精灵表
1. 在 Godot 编辑器的 **FileSystem** 面板中
2. 右键点击 `assets/sprites/` 文件夹
3. 选择 **Show in File Manager**
4. 将您的 3 个 PNG 文件复制进去
5. Godot 会自动导入

#### 步骤 3：配置精灵表导入选项

**对于每个精灵表文件：**
1. 点击文件（如 `player_run.png`）
2. 在 **Import** 面板中设置：
   - **Preset:** 2D Pixel
   - **Filter:** Nearest（保持像素清晰）
   - **Mipmaps:** ❌ 关闭
   - 点击 **Reimport**

#### 步骤 4：创建 SpriteFrames 资源

**方法 A：使用 Animation 面板（可视化）**
1. 打开 `scenes/player.tscn`
2. 选中 `AnimatedSprite2D` 节点
3. 在属性面板中点击 **Sprite Frames** → **New SpriteFrames**
4. 点击 **Sprite Frames** → **Open Editor**
5. 在动画编辑器中：
   - 左侧点击 **Default** → 重命名为 `idle`
   - 点击 **+** 添加新动画 `run` 和 `jump`

**方法 B：分割精灵表**
1. 在 SpriteFrames 编辑器中
2. 选择动画（如 `run`）
3. 点击 **Add Frames from Sprite Sheet**
4. 选择 `player_run.png`
5. 设置：
   - **Horizontal:** 帧数（如 8）
   - **Vertical:** 1（如果只有一行）
   - 点击 **OK**

#### 步骤 5：配置动画参数

**待机动画（idle）：**
- Speed: 5-8 FPS
- Loop: ✅ 开启

**移动动画（run）：**
- Speed: 10-12 FPS
- Loop: ✅ 开启

**跳跃动画（jump）：**
- Speed: 15-20 FPS
- Loop: ❌ 关闭（只播放一次）

## 🔧 代码说明

### player.gd 核心功能

```gdscript
# 移动参数
@export var speed: int = 200          # 移动速度
@export var jump_force: int = -400    # 跳跃力度（负数=向上）
@export var gravity: int = 800        # 重力

# 动画状态管理
var current_animation = "idle"        # 当前动画
var facing_right = true               # 朝向

# 物理更新
func _physics_process(delta):
    # 1. 应用重力
    if not is_on_floor():
        velocity.y += gravity * delta
    
    # 2. 跳跃检测
    if Input.is_action_just_pressed("jump") and is_on_floor():
        velocity.y = jump_force
        play_animation("jump")
    
    # 3. 水平移动
    var direction = Input.get_axis("move_left", "move_right")
    if direction != 0:
        velocity.x = direction * speed
        # 更新朝向和动画
        play_animation("run")
    else:
        velocity.x = 0
        play_animation("idle")
    
    # 4. 执行移动
    move_and_slide()
```

## 🎨 Pixel Studio 导出技巧

### 1. 保持像素清晰
- 导出时使用 **Nearest Neighbor** 缩放
- 在 Godot 中设置 Filter 为 **Nearest**

### 2. 透明背景
- 确保 Pixel Studio 背景层是透明的
- 导出时选择 PNG 格式

### 3. 对齐帧
- 所有动画帧使用相同画布尺寸
- 角色脚部对齐底部

### 4. 帧率建议
| 动画 | 帧数 | 建议 FPS |
|------|------|---------|
| 待机 | 4-8 | 5-8 |
| 移动 | 8-12 | 10-12 |
| 跳跃 | 4-8 | 15-20 |

## 🐛 常见问题

### Q1: 动画模糊或有锯齿
**解决：**
1. 选中精灵表文件
2. Import 面板 → Filter 改为 **Nearest**
3. 点击 **Reimport**

### Q2: 动画不播放
**检查：**
1. SpriteFrames 是否正确配置
2. 动画名称是否匹配（idle/run/jump）
3. 代码中的 `play_animation()` 是否调用

### Q3: 角色翻转错误
**解决：**
```gdscript
# 在 play_animation() 后添加
animated_sprite.flip_h = not facing_right
```

### Q4: 碰撞体不对
**调整：**
1. 打开 `player.tscn`
2. 选中 `CollisionShape2D`
3. 调整 Shape 的 Size
