## 🎯 游戏简介

**主角 Toyi 为了揭露「塔」的真相，踏上了一条不归路。**

在这座充满谜团与危险的塔中，Toyi 将：
- 🔍 探索未知的区域
- ⚔️ 获得新的能力
- 👊 面对强大的敌人
- 📖 逐渐揭开隐藏在塔深处的秘密

## 🌍 世界观

### 「塔」的设定

- **起源：** 2157 年「诺亚计划」失败后，人类在宇宙中漂流的末日方舟
- **结构：** 五层垂直社会（海拔即阶级）
  - 🏚️ **消失层（塔底）：** 废弃物、融合者、被遗忘的人
  - ⚙️ **齿轮层：** 工厂、生产线、工人阶级
  - 🧬 **肿瘤层：** 奢华宫殿、基因改造、富人阶层
  - 🔥 **燃烧层：** 废热处理、流放者、反抗组织
  - 🏛️ **神殿层：** 中央控制室、A0023、最终真相

### 核心角色

## 🎮 核心玩法

### 操作方式

| 操作 | 按键 | 功能 |
|------|------|------|
| 移动 | A/D | 左右移动 |
| 跳跃 | Space | 可变高度跳跃 |
| 攻击 | J | 3 段连击 |
| 下劈 | ↓+J（空中） | 向下攻击 |
| 冲刺 | K | 无敌帧位移 |
| 闪避 | L | 翻滚闪避 |
| 治疗 | E | 恢复 HP |

### 游戏流程

```
[到达新区域] → [安全区] → [探索] → [战斗+解密] → [Boss] → [获得能力] → [下一区域]
```

### 装备系统

- **6 种武器：** 残刃、数据切割者、相位之刃等
- **14 种配件：** 生命扩展核心、锋利暗影协议等
- **6 种流派：** 速通流、坦克流、输出流等

## 💡 设计亮点

### 1. 碎片化叙事
- 世界观藏在物品描述中
- 玩家需要主动探索拼凑真相
- 多层信息设计（功能→背景→真相）

### 2. 纯粹理性 Boss
- A0023 是完全理性的 AI
- 不会怀疑自己的决定
- 用逻辑否定情感
- 玩家通过战斗发现真相

### 3. 虚假的呼唤
- 23 次呼唤不是 tong 在呼唤
- 而是 A0023 在反复播放记忆
- 试图理解一个永远无法理解的东西：爱

### 4. 装备策略
- 点数限制系统
- 6 种流派组合
- 战斗/探索/挑战配置
