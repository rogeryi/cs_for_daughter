## 🎨 二、游戏设计总结

### 2.1 核心玩法循环

```
探索关卡 → 发现敌人 → 战斗（跳跃+攻击）
    ↓
消灭敌人 → 获得分数 → 触发Boss战
    ↓
Boss战斗 → 击败Boss → 胜利
```

### 2.2 设计亮点

#### ⭐ **平台敌人智能巡逻**
- 问题：平台上的敌人会掉下去
- 解决：检测所在平台，设置巡逻边界
- 效果：敌人只在平台范围内移动

#### ⭐ **物理化跳跃系统**
- 问题：跳跃感觉不真实、滞空时间长
- 解决：非对称重力 + 可调参数
- 效果：紧凑有力的跳跃手感

#### ⭐ **二段跳视觉反馈**
- 问题：不知道二段跳是否触发
- 解决：粒子特效系统
- 效果：华丽的视觉确认

#### ⭐ **中文显示优化**
- 问题：中文字符显示为方框
- 解决：加载系统中文字体
- 效果：完美显示中文UI

## 🔧 三、技术实现要点

### 3.1 碰撞检测

```python
# 平台碰撞（玩家）
if (玩家.x + 宽度 > 平台.x and 
    玩家.x < 平台.x + 宽度 and
    玩家.y + 高度 >= 平台.y and
    玩家.velocity_y >= 0):
    玩家.y = 平台.y - 高度
    玩家.on_ground = True

# 敌人平台碰撞（相同逻辑）
```

### 3.2 跳跃物理

```python
# 非对称重力
if velocity_y < 0:  # 上升
    gravity = 0.7
else:               # 下落
    gravity = 1.2

# Coyote Time
if on_ground:
    coyote_timer = 8
else:
    coyote_timer -= 1
```

### 3.3 按键去抖

```python
# 检测按键按下瞬间
jump_pressed = keyboard.up
jump_just_pressed = jump_pressed and not jump_was_pressed
jump_was_pressed = jump_pressed

# 只在按下瞬间触发跳跃
if jump_just_pressed:
    执行跳跃()
```
