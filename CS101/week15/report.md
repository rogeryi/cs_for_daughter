### 角色框架、成长与字典

Player拥有生命、攻击、防御、装备、背包、等级、经验和金币。
gain_exp使用while，保证一次较多经验可以连续升级。每级增加20生命上限、
3攻击、1防御；下一等级所需经验为60×当前等级。

to_dict把对象变成JSON可保存的数据；from_dict校验输入并重建对象。
例如玩家等级会决定基础属性，避免存档同时保存两套互相冲突的基础数值。
装备加成从物品定义表重新计算。

### 存档、读档与异常处理

原实现只保存Player，导致剧情和队友丢失。新版保存整个GameSession：

```python
{
    "version": 2,
    "session": {
        "player": ...,
        "stage": ...,
        "displayed_stage": ...,
        "daytime": ...,
        "recruited": ...,
        "choices": ...,
        "completed": ...,
        "rewards": ...
    }
}
```

保存只在城镇安全节点开放。先写临时文件、备份旧文件，再替换正式文件。
加载时先验证新对象，再替换当前会话；文件缺失或格式错误会显示提示。
旧存档只能按实际记录的誓印推断部分进度，不能凭空恢复未保存的选项。
