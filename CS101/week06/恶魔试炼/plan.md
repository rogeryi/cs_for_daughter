## 📋 项目概述

### 游戏简介
《恶魔试炼》是一款像素风格的**垂直向上平台跳跃**小游戏，讲述了一只名叫**西蒙**的社畜恶魔的职场晋升故事。

作为地狱公司最底层的小恶魔，西蒙必须通过不断**向上跳跃**，通过来自**上司恶魔**的一系列"考验"，才能成为一只合格的社畜。这些考验包括：
- **KPI考核**：不断向上跳跃通过层层平台（晋升阶梯）
- **同事竞争**：躲避或击败其他恶魔员工
- **加班挑战**：躲避陷阱（地刺=老板的怒火）
- **终极考核**：到达顶层（通过试用期）

**游戏口号**：*"在地狱工作，才是真正的社畜试炼！向上跳跃，逃离底层！"*

### 设计目标
1. **巩固基础知识**: 列表、for循环、while循环、条件判断
2. **实践游戏开发**: 完整的游戏循环、碰撞检测、状态管理
3. **渐进式复杂度**: 从简单到复杂，适合高中生理解
4. **趣味性强**: 社畜主题幽默搞笑，让学习更有意思
5. **引发共鸣**: 用游戏化的方式理解职场文化

## 🎮 游戏设计

### 核心玩法

```
玩家控制 → 左右移动 + 向上跳跃 → 躲避/击败敌人 → 不断上升 → 到达顶层
```

**游戏特点**：
- 垂直向上滚动（类似Doodle Jump）
- 平台随机生成
- 屏幕自动跟随玩家上升
- 掉落底部即失败

### 游戏元素

| 元素 | 描述 | 涉及知识点 |
|------|------|-----------|
| **西蒙（玩家）** | 社畜小恶魔，可移动、跳跃、使用"加班技能" | 列表、状态机 |
| **平台** | 红色地狱砖（静态和移动） | 碰撞检测、列表 |
| **同事恶魔（敌人）** | 巡逻型竞争对手，触碰扣"职场值" | for循环、条件判断 |
| **道具** | 咖啡（恢复HP）、摸鱼时间（临时无敌） | 列表、随机数 |
| **终点** | 老板办公室（到达=通过试用期） | 条件判断 |
| **陷阱** | 地刺（老板的怒火）、KPI报表（伤害） | 碰撞检测 |

### 操作方式

| 按键 | 功能 | 游戏内解释 |
|------|------|----------|
| **A / D** 或 **← / →** | 左右移动 | 在工作场所移动 |
| **Space** 或 **W** 或 **↑** | 向上跳跃 | 努力晋升 |
| **J** | 使用"加班技能"（攻击） | 展现工作热情 |
| **R** | 重新开始（被辞退后） | 重新入职 |

```python
def check_platform_collision(player, platforms):
    if player.vy > 0:  # 只在下落时检测
        for platform in platforms:
            if player.bottom >= platform.top and player.bottom <= platform.top + 10:
                if player.x >= platform.left and player.x <= platform.right:
                    player.y = platform.top - player.height
```

```python
def update_enemies(enemies):
    for enemy in enemies:
        enemy['x'] += enemy['vx']
        
        # 碰到边界反转
        if enemy['x'] <= 0 or enemy['x'] >= 780:
            enemy['vx'] *= -1

# 攻击检测
def check_attack(player, enemies):
    if player.is_attacking:
        attack_rect = get_attack_rect(player)
        for enemy in enemies:
            if attack_rect.colliderect(enemy['rect']):
                enemy['hp'] -= 20
                if enemy['hp'] <= 0:
                    enemies.remove(enemy)
```

### 给Amos的建议

1. **不要急于完美**
   - 先用矩形代替精灵
   - 先实现功能，后优化外观
   - 完成比完美更重要

2. **逐步测试**
   - 每完成一个功能就测试
   - 不要等全部写完再测试
   - 小步快跑，及时发现问题

3. **理解每一行代码**
   - 不要照抄代码
