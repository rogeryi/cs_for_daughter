## 📋 音效系统概述

### Pygame Zero音效系统特点

✅ **无需导入pygame** - PGZ自带sounds对象  
✅ **自动加载** - sounds/文件夹中的音效自动识别  
✅ **简单易用** - `sounds.文件名.play()`  
✅ **支持循环** - `sounds.bgm.play(-1)`  
✅ **支持格式** - WAV, OGG, MP3

## 🔧 音效获取方式

### 方式1: 在线生成器（推荐初学者）

**bfxr.net** - 8位音效生成器
1. 访问 https://www.bfxr.net/
2. 点击不同按钮生成音效
   - **Jump** - 生成跳跃音效
   - **Hit/Hurt** - 生成受伤音效
   - **Pickup/Coin** - 生成胜利音效
   - **Explosion** - 生成失败音效
3. 点击 **Export Wav** 下载
4. 重命名为对应的文件名

**优点**: 
- 免费
- 无需注册
- 8位风格适合像素游戏
- 即时生成

### 方式2: 免费音效库

**freesound.org**
1. 注册账号（免费）
2. 搜索关键词：
   - "jump 8bit"
   - "land impact"
   - "game over"
   - "victory fanfare"
3. 筛选许可证：Creative Commons 0
4. 下载WAV格式

**opengameart.org**
1. 搜索 "sound effects"
2. 按许可证筛选
3. 下载音效包

### 方式3: 自己录制（有趣但不推荐）

用手机录制真实声音，然后处理：
- 跳跃 - 拍手声
- 落地 - 拍桌子
- 失败 - 叹气声

使用Audacity等软件处理成8位风格。

### 1. 创建音效播放函数

```python
def play_land():
    """播放落地音效"""
    try:
        sounds.land.play()
    except:
        pass

def play_fail():
    """播放失败音效"""
    try:
        sounds.fail.play()
    except:
        pass

def play_win():
    """播放胜利音效"""
    try:
        sounds.win.play()
    except:
        pass

def play_menu():
    """播放菜单音效"""
    try:
        sounds.menu.play()

        pass

    """播放背景音乐（循环）"""
```

### 2. 在关键位置调用音效

#### 跳跃时（在 `update_player()` 中）

```python
def update_player():
    global game_state
    
    # ... 原有代码 ...
    
    # 跳跃
    if (keyboard.space or keyboard.w or keyboard.up) and not player['is_jumping']:
        player['vy'] = player['jump_force']
        player['is_jumping'] = True
        player['jump_state'] = 'charge'
        player['jump_frame'] = 1
        player['jump_timer'] = 0
        play_jump()  # ← 添加这行
```

#### 落地时（在碰撞检测中）

```python
def check_platform_collision():
    # 只在下落时检测
    if player['vy'] > 0:
        for platform in platforms:
            if (player['y'] + player['height'] >= platform.top and
                player['y'] + player['height'] <= platform.top + 15 and
                player['x'] + player['width'] > platform.left and
                player['x'] < platform.right):
                
                player['y'] = platform.top - player['height']
                player['vy'] = 0
                player['is_jumping'] = False
                
                # 重置跳跃状态
                if player['jump_state'] in ['fall', 'land']:
                    player['jump_state'] = 'idle'
                    player['jump_frame'] = 1
                
                play_land()  # ← 添加这行
```

#### 游戏结束时

```python
def check_game_over():
```

```python
def check_win():
```

```python
def on_key_down(key):
    global game_state, start_time
    
    if key == keys.ENTER:
        play_menu()  # ← 添加这行
        if game_state == 'menu':
            game_state = 'playing'
            start_time = time.time()
            play_bgm()  # 开始播放背景音乐

            restart_game()
            play_bgm()  # 重新开始时播放BGM
```

## 🎨 音效设计建议

### 跳跃音效
- **风格**: 上升音调（从低到高）
- **时长**: 0.2-0.3秒
- **特点**: 轻快、有活力
- **bfxr设置**: 
  - Jump 预设
  - Pitch: 从低到高
  - Duration: 短

### 落地音效
- **风格**: 短促的撞击声
- **时长**: 0.1-0.2秒
- **特点**: 干脆、有力
- **bfxr设置**:
  - Hit/Hurt 预设
  - Short duration
  - Low pitch

### 失败音效
- **风格**: 下降音调（从高到低）
- **时长**: 1-2秒
- **特点**: 悲伤、低沉
- **bfxr设置**:
  - Powerup 预设（反向）
  - Long duration
  - Pitch下降

### 胜利音效
- **风格**: 上升+庆祝
- **时长**: 2-3秒
- **特点**: 欢快、激励
- **bfxr设置**:
  - Pick up/Coin 预设
  - Multiple tones
  - Major key

### 背景音乐
- **风格**: 地狱/紧张感
- **时长**: 30-60秒循环
- **特点**: 节奏感强、不抢风头
- **推荐**: 
  - 8位电子音乐
  - 低音为主
  - 中等节奏

## 🔍 常见问题

### Q1: 音效不播放？
**原因**: 
- sounds/文件夹不存在
- 文件名不匹配
- 文件格式不支持

**解决**:
```bash
# 检查文件夹
ls -la sounds/

# 检查文件名（区分大小写）
jump.wav  # 正确
Jump.wav  # 错误
JUMP.WAV  # 错误

# 推荐格式
.wav 或 .ogg
```

### Q2: 音效音量太小/太大？
**解决**: 使用Audacity调整音量
1. 打开音效文件
2. 效果 → 放大/淡入淡出
3. 导出为WAV

### Q3: 如何循环播放BGM？
```python
sounds.bgm.play(-1)  # -1 表示无限循环
```

### Q4: 如何停止BGM？
```python
sounds.bgm.stop()
```

### Q5: 如何控制音量？
```python
# PGZ不直接支持音量控制
```
